# 📱 Directorio de Distribución APK — Transportes La Solución

Este directorio aloja el instalador APK para los choferes y administradores de la empresa.
Se descarga directamente desde GitHub Pages en la **Ventana de Chofer**.

## Archivo de Instalación
- **Nombre:** `TransportesLaSolucion-Chofer.apk`
- **Paquete:** `com.transporteslasolucion.chofer`
- **Versión:** 1.0.0
- **Requisitos:** Android 8.0 o superior con GPS habilitado.
